# Christmas Tree Touch & Gesture

一个由 Three.js 和 MediaPipe 构建的 3D 粒子圣诞树页面，支持触控、摄像头手势和照片上传。

## 页面

- [打开圣诞树页面](christmas_tree_touch%26gesture.html)
- [背景音乐](audio/christmas.mp3)

## 本地运行

由于摄像头权限和浏览器模块限制，建议通过本地 Web 服务器打开：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/christmas_tree_touch%26gesture.html
```
